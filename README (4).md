# Registration System (C++)

A console-based user registration and login system built in C++ using OOP and file handling.

## Features
- User Sign-Up with duplicate username check
- Login with username & password verification
- Forgot Password (identity verified via matching username & email — no real email is sent)
- Data stored in a local text file (loginData.txt)

## How to Run

### Using Command Line (g++)
```
g++ RegistrationForm.cpp -o RegistrationForm.exe
.\RegistrationForm.exe
```

## Concepts Used
- Object Oriented Programming (Classes)
- File Handling (fstream)
- String manipulation
